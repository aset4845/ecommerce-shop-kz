# E-commerce Shop (KZ)

Интернет-магазин на **PHP + MySQL** с клиентской витриной и панелью администратора. Часть интерфейса переведена и доработана на **казахский язык**.

## Возможности

- Каталог товаров: категории, избранные/новые/популярные товары
- Корзина и оформление заказа
- Регистрация и личный кабинет покупателя (адрес доставки, история заказов)
- Админ-панель: товары, заказы, категории, слайдеры, страницы, настройки магазина, подписчики
- Управление цветами/вариациями товара (раздел доработан на казахском языке)

## Технологии

- PHP, MySQL (PDO)
- HTML, CSS, Bootstrap, JavaScript

## Установка (XAMPP)

1. Скопируйте папку проекта в `C:\xampp\htdocs\`.
2. Запустите **Apache** и **MySQL** в XAMPP Control Panel.
3. Создайте базу данных `ecommerceweb` и импортируйте дамп `DATABASE FILE/ecommerceweb.sql` через phpMyAdmin.
4. При необходимости поправьте параметры подключения к БД в файлах подключения проекта.
5. Откройте в браузере: `http://localhost/<папка_проекта>/`
